# Day note schema

Each active day should get one durable note.

```markdown
## YYYY-MM-DD — Title

Short summary paragraph.

### Dominant themes
- theme 1
- theme 2

### What changed
- concise bullets

### What this seems to teach
- lesson 1
- lesson 2

### Commits covered
- `abcd1234` Subject
- `efgh5678` Subject
```

Guidelines:

- Write for resumption first, prose second
- Mention recurring pain loops if present
- Mention if this day looks like a release-stabilization burst, a pivot, a docs catch-up day, or a rollback day

See `sample-day-note.md` for a filled example and common anti-patterns.
